Engineering AI Evaluation Rubrics

This repository contains structured rubric examples for evaluating AI-generated engineering and STEM responses. The focus is on technical accuracy, reasoning quality, numerical consistency, assumptions, and answer completeness.

Focus Areas
Engineering reasoning evaluation
STEM prompt scoring
Model-response grading
Numerical accuracy checks
Assumption and constraint validation
Reviewer calibration examples

Example Rubric Categories
Correct interpretation of the problem
Valid engineering assumptions
Correct formulas and methods
Accurate numerical result
Proper unit handling
Clear explanation of reasoning
Identification of model errors
